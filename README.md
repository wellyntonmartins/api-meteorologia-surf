API para auxiliar na escolha do melhor local para praticar surf com base em condições meteorológicas e de mar.

## 🎯 Objetivo

Transformar dados de previsão em informações úteis para que usuários consigam identificar praias com melhores condições para surf em um determinado período.

## 🌊 O que a aplicação oferece

- previsões de ondas, vento e direção do mar
- comparação de condições entre diferentes praias
- identificação de locais mais adequados ao perfil do surfista
- estrutura de API REST organizada e escalável em TypeScript

## ▶️ Como executar

1. Instale as dependências:

```bash
npm install
```

2. Inicie a aplicação em modo de desenvolvimento:

```bash
npm run dev
```

3. A API estará disponível em:

```bash
http://localhost:3000
```

## 📍 Endpoints

### Forecasts

- `GET /forecasts` — retorna previsões de surf
